# LINGUAGEM MARKDOWN:
É uma linguagem de marcação, onde é de mais fácil leitura. Podemos usar em qualquer arquivo .md ou .markdown | ISSUES ou PULL REQUESTS.
Common Markdown: Fácil conversão entre Markdown e HTML.

MARKDOWN:
Negrito: **exemplo** ou __exemplo__
Itálico: *exemplo* ou _exemplo_
Risco: ~~exemplo~~
Sublinhado: Não é possível "sublinhar" uma palavra com MARKDOWN. Para sublinhar, teremos que usar linguagem HTML: <ins>PROGRAMAÇÃO</ins> "detalhe: não se usa "< u >" e sim "< ins >"

Linha fraquinha embaixo do título: 
exemplo TÍTULO
--- ou ***

Podemos misturar configurações

Exemplo:
Negrito e Italico: _*Estou testando essa frase!*_

Títulos:
# Título nível 1 (depois disso, escrever!)
